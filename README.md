## Как добавить новую лекцию

1. Создать папку: `<Курс>/Лекция NN — короткое название/`
2. Положить туда финальный `.pptx` (один файл, без суффиксов «копия/final»,
   без рукописных ink-пометок с проектора).
3. Обновить таблицу выше: дата лекции + статус.
4. Закоммитить и запушить:

```bash
cd ~/lectures
git add -A
git commit -m "Лекция NN <курс>: <тема>"
git push
```

## Заметки

- **Рукописные пометки с проектора не заливаются.** PowerPoint сохраняет
  штрихи ручкой как ink-объекты внутри pptx — перед коммитом почистить
  (в Лекции 01 ВШЭ так было удалено 15 пометок со слайдов 9, 10, 13–16,
  18–23, 25, 33, 35).
- PDF-версии и черновики не храним — только исходники `.pptx`.
- Тяжёлые файлы данных, чекпоинты, датасеты — не для этого репо.
