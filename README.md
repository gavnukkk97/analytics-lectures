## Как заводить новое занятие

1. Создать папку: `Лекция NN (ГГГГ-ММ-ДД) — короткая тема дня`
2. Внутри:
   - `README.md` дня — 5–10 строк: о чём сегодняшний день, что обсуждаем,
     какие выводы унести; внизу список файлов;
   - финальные деки с нумерацией порядка показа: `01 ….pptx`, `02 ….pptx`
3. Добавить строку в таблицу выше.
4. Закоммитить и запушить:

```bash
cd ~/lectures
git add -A
git commit -m "Лекция NN — тема дня"
git push
```

## Правила потока

- Заливаем **финальные** деки в день лекции: один файл на часть показа,
  без суффиксов «копия / final / v2».
- **Без рукописных ink-пометок с проектора** — PowerPoint сохраняет штрихи
  ручкой внутри pptx; перед коммитом чистим (в Лекции 01 так убрали 15
  пометок со слайдов 9–35 деки Х5).
- PDF-версии и черновики не храним — только исходники `.pptx`.
- Тяжёлые данные, датасеты, чекпоинты — не для этого репозитория.
