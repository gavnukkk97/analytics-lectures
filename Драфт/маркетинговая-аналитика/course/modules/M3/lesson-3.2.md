# Урок 3.2 — UTM-метки: гигиена данных привлечения

**Цель урока:** освоить структуру UTM, правила нейминга и динамические подстановки; построить регламент разметки для команды; понять, почему одна опечатка = потерянный канал, и как продукт помогает маркетингу ценностью для разметки сегментов.

**Перед уроком:** урок 3.1 (карта каналов).

## Зачем это аналитику

Без разметки система аналитики видит «пришли с какого-то сайта» — и всё. С UTM видна конкретная кампания, объявление и ключевое слово. Половина «странных» результатов в отчётах по каналам — это не маркетинг, а опечатки в метках (`test` и `Test` — разные кампании). Для маркетинг-аналитика UTM-дисциплина — то же, что чистка данных для DS: не гламур, но без неё всё downstream мертво. И это ещё и вход в ML-атрибуцию (4.3): модели обучаются на цепочках касаний, качество которых задаётся разметкой.

## Теория

### 1. Структура: 5 параметров (3 обязательных)

```
https://edadoma.ru/?utm_source=yandex&utm_medium=cpc
     &utm_campaign=spring_delivery_msk
     &utm_content=banner_top|{creative_id}
     &utm_term={keyword}
```

| Параметр | Обяз. | Что кодирует | Пример |
|---|---|---|---|
| `utm_source` | ✔ | площадка/платформа | `yandex`, `vk`, `telegram`, `email` |
| `utm_medium` | ✔ | тип трафика | `cpc`, `cpm`, `email`, `referral` |
| `utm_campaign` | ✔ | кампания | `spring_delivery_msk` |
| `utm_content` | — | различение объявлений/креативов | `banner_top`, `{creative_id}` |
| `utm_term` | — | ключевое слово / доп. информация | `{keyword}`, `2026-04-promo` |

### 2. Правила нейминга (и почему они не обсуждаются)

1. **Только латиница** (транслит: `muzhskie-palto`), **регистр важен** (`yandex` ≠ `Yandex`), **разделитель — дефис или подчёркивание**, никаких пробелов.
2. **Единый порядок** от общего к частному: source → medium → campaign → content → term (Директ/Метрика чувствительны, Google — нет; единый порядок для всех).
3. **Стандартизированный справочник кампаний** на команду: `проект_сегмент_гео_месяц`, а не `derevyannie_stoly23_test_fb_wide`.
4. **Один `?` в URL** — перед первой меткой; остальные через `&`.
5. **Дубли страниц в поиске**: `rel="canonical"` на сайте; для Яндекса — `Clean-param` в robots.txt (перечислить utm-параметры, чтобы поисковик не индексировал ссылки с метками как отдельные страницы).

### 3. Динамические подстановки — сила автоматизации

Вместо ручного `ad1/ad2` — макросы рекламных систем: `{campaign_id}`, `{creative_id}`, `{keyword}`, `{gbid}`. Тогда `utm_campaign={campaign_id}` даёт 1000 кампаний без 1000 ручных ссылок, а справочник имён подтягивается джойном с API рекламного кабинета. Ручная разметка — для медиабаеров и рассылок, где макросов нет; там — шаблоны и двойная проверка.

### 4. Регламент разметки (мини-конституция команды)

1. Справочник значений source/medium — зафиксирован, новые — только через аналитика.
2. Шаблон ссылки для каждой системы (с макросами) — в общем доступе.
3. Никаких тестовых меток в проде без префикса `test_`.
4. Еженедельный аудит: отчёт «кампании с мусорными/внеправильными метками» → владельцам.
5. Реферальные/кросс-промо рассылки тоже размечаются (email-трафик без меток утонет в referral).

### 5. Продукт помогает маркетингу: разметка как мост

UTM — про канал; но сегменты для кампаний («заказывают суши по пятницам») берутся из продуктовой аналитики (1.3). Связка: продуктовые сегменты → выгрузка в рекламные системы/CRM → кампании на сегменты → разметка кампаний возвращает эффект в данные. Без продуктовой ценности разметка превращается в бухгалтерию каналов.

## Разбор на данных

Аудит 30 ссылок «ЕдаДома» (учебный пример): 4 ссылки без `utm_medium` (трафик сольётся в «не определён»); 2 с кириллицей в campaign (`акция_апрель` — в части систем потеряется); 3 с пробелами (обрежется на первом пробеле); 1 с `Yandex` против 20 с `yandex` — канал размножен; blogger-пост использует общую ссылку без content — 3 блогера в одной строке отчёта. Итог аудита: ~30% бюджета месяца — в «слепой зоне» или с искажениями. Чинится за день справочником + шаблонами; цена невнимания — месяц испорченных решений по бюджету.

## Подводные камни

1. **Опечатка/регистр = новый «канал»** в отчётах: дашборд зарастает мусором, топ-каналы размываются.
2. **Только статические метки** вместо макросов — ручной труд, меньше данных (по сути нельзя посчитать вклад креативов).
3. **Перезапись меток редиректами** (партнёрские сети ставят свою UTM поверх) — договоритесь о сохранении исходной в content/term.
4. **Каннибализация SEO** дубиками URL — canonical + Clean-param обязательны.
5. **Смена справочника без миграции** — исторические отчёты рвутся: изменения версонируйте (справочник с датой действия).

## Домашнее задание

1. Найдите ошибки: `сайт.ru/акция?utm_source=Vk&utm_medium=cpm&utm_campaign=Новая_акция&utm_content=баннер 1`

<details>
<summary>Ответ</summary>

Кириллица в URL и campaign (потеряется/закодируется), `Vk` ≠ `vk` (регистр — новый источник), пробел в `баннер 1` (обрежется), нет utm_term — допустимо; путь `/акция` тоже кириллица. Правильно: `site.ru/promo?utm_source=vk&utm_medium=cpm&utm_campaign=new_promo&utm_content=banner_1`.
</details>

2. Зачем `utm_content={creative_id}` вместо `banner_top`?

<details>
<summary>Ответ</summary>

Масштаб и точность: сотни креативов без ручного труда, вклад каждого креатива виден отдельно, справочник имён подтягивается джойном с API. Статические значения годятся для малого числа ручных размещений (блогеры, рассылки).
</details>

3. Команда «всегда так называла кампании». Как внедрить регламент без войны?

<details>
<summary>Ответ</summary>

Через боль и экономику: показать аудит (доля бюджета в слепой зоне), предложить справочник как «словарь», а не «запрет»; автоматизировать (шаблоны с макросами — меньше ручной работы); правило «новые кампании — по стандарту, старые — как есть до конца квартала»; еженедельный отчёт по качеству без публичной порки.
</details>

## Шпаргалка

1. UTM: source/medium/campaign обязательны; content/term — детали; порядок и латиница едины.
2. Регистр важен, пробелы запрещены, один `?`; canonical/Clean-param против дубиков.
3. Макросы `{campaign_id}/{creative_id}/{keyword}` — автоматизация и детализация до креатива.
4. Регламент: справочник + шаблоны + префикс test_ + еженедельный аудит качества.
5. Разметка — мост: сегменты из продукта → кампании → эффект обратно в данные (вход в ML-атрибуцию).
