# Урок 3.1 — Карта каналов: где брать трафик и чем это измерять

**Цель урока:** увидеть всё поле каналов привлечения; понять, какие типы рекламы на какие показатели продукта работают, где быстрые деньги и где игла; научиться выбирать метрику оценки под тип канала.

**Перед уроком:** уроки 1.2–1.3 (цели), 2.1 (метрики привлечения).

## Зачем это аналитику

«У нас плохо с трафиком» — не постановка. Каналов десятки, у каждого своя механика, скорость, цена и способ измерения. Аналитик, который не знает карту каналов, соглашается мерить всё по CPO — и получает вечный спор с медиабайерами, чьи баннеры «не работают». Карта каналов — это одновременно карта того, **какой канал чем измерять**.

## Теория

### 1. Карта каналов

| Группа | Каналы | Как работает | Скорость | Измеримость |
|---|---|---|---|---|
| **Платный перформанс** | контекст (поиск), таргет/медийка, ритейл-медиа, агрегаторы | покупаем клики/показы с целью | мгновенно | клик-трекинг, UTM — полная |
| **Поиск/SEO** | органика поиска, маркетплейсы | контент и тех. база растят выдачу | месяцы–годы | реферер (без UTM), «organic» |
| **Бренд-трафик** | брендовые запросы, direct | люди сами приходят | следствие инвестиций | брендовые запросы, direct |
| **Инфлюенсеры** | блогеры, Telegram-каналы | доверие аудитории лидера | среднее | UTM-ссылки, промокоды |
| **Партнёрки/рефералы** | CPA-сети, реферальные программы | платим за результат | среднее | партнёрский ID, промокоды |
| **Кросс-промо** | свои базы других продуктов, пуши | «бесплатный» трафик внутри холдинга | мгновенно | deep-links/промокоды |
| **Офлайн/медийное** | ТВ, радио, наружка, кино | охват + память | недели–месяцы | **не размечается** — спецметоды (3.3) |
| **PR/контент** | СМИ, статьи, соцсети бренда | репутация | медленно | referral, брендовые запросы |

### 2. Тип рекламы → показатель продукта

- **Поисковый контекст** ловит сформированный спрос («заказать пиццу сейчас») → конверсия высокая, CPO низкий, объём ограничен спросом.
- **Медийка/таргет** формируют спрос (показы «в пустоту» для скриншот-клика) → конверсия с клика ниже, зато объём и охват; эффект частично view-through (без клика — 4.3).
- **ТВ/наружка** — верх воронки для всех: рост брендовых запросов, direct-заходов, органики; заказы придут «через чужую» разметку.
- **Блогеры** — доверие: конверсия средняя, но retention когорт часто выше (пришли «за личностью»).
- **Кросс-промо** — дёшево, но аудитория «своя»: следите за каннибализацией баз и частотой (6.1).

### 3. Быстрые деньги и игла

Эволюция типовой компании: (1) перформанс — мгновенный поток, аукцион разгоняет цену; (2) параллельно строятся медленные активы: SEO, бренд, рефералы, контент; (3) когда CAC перформанса растёт при стабильном LTV — «слезать с иглы»: перекладывать бюджет в активы, поднимать LTV. Сигналы: LTV/CAC когорт канала < 1–3; рост частоты показов на юзера при падении CTR; выкуп ядра аудитории.

### 4. Правило метрики под канал

Канал, который кликается, — мерим по цепочке UTM→заказ (CAC, ROMI). Канал, который показывается без клика, — view-through и бренд-прокси (3.3, 4.3). Канал, который «создаёт спрос», — длинным горизонтом LTV когорт и брендовыми запросами. Одна метрика на все каналы = систематическая несправедливость к верху воронки.

## Разбор на данных

Портфель «ЕдаДома» (учебные числа, месяц): контекст — CAC 420 ₽, LTV/CAC 1,8; таргет — CAC 610 ₽, 1,1; блогеры — CAC 780 ₽, 1,6 (LTV выше за retention); ТВ-тест в 2 городах — CAC «невидим» в трекере, брендовые запросы +38%, direct +12%, итоговая оценка через гео-сравнение ≈ 900 ₽. Выводы: контекст — рабочая лошадка у потолка объёма; таргет — на грани, тестировать связки; блогеры — дорогой вход, дорогой LTV (масштабировать с контролем качества); ТВ — хуже по «CAC», но растит всё остальное: смотреть общий эффект канала на рынок, а не только прямые конверсии.

## Подводные камни

1. **Сравнивать CPO перформанса с CPO блогеров** без retention: дешёвый вход может быть дорогим клиентом (и наоборот).
2. **Органика «бесплатная»** — пока не посчитаете стоимость контента/SEO-команды; её «CAC» — opex, а не 0.
3. **Кросс-промо не бесплатный**: каннибализация баз, усталость от пушей, искажение когорт (помечайте источник!).
4. **Аукцион нагревается молча**: CAC ползёт по 3–5% в неделю — следите трендом, а не месячным срезом.
5. **Микс каналов ≠ сумма эффектов**: каналы взаимодействуют (таргет «дожимает» тех, кто увидел ТВ) — финальная оценка портфеля только на уровне гео/экспериментов (М5).

## Практика

Практика по уроку будет добавлена финальным блоком курса (карта каналов × метрики × риски на данных своей компании).

## Домашнее задание

1. Канал с самым низким CPO приносит когорты с retention вдвое ниже среднего. Расширяете?

<details>
<summary>Ответ</summary>

Считать LTV/CAC по когортам канала: если LTV ниже пропорционально — канал сжигает деньги на недоживающих клиентах; сравнить с альтернативами, проверить сегментинг (может, внутри канала есть поды с нормальным retention — резать не весь канал, а настройки).
</details>

2. Бренд-запросы выросли на 30% при запуске ТВ. Какие ещё метрики посмотрите, прежде чем решить «ТВ работает»?

<details>
<summary>Ответ</summary>

Direct-трафик и установы (гео-волна), органика по небрендовым запросам (созревание спроса), конверсия брендовых кампаний (перехват — 4.3), CAC смешанный до/после по гео, retention когорт периода ТВ. И проверить сезонность/конкурентов: без контрольной гео-группы рост может быть общерыночным.
</details>

3. Постройте для своего продукта строку карты: канал → метрика → скорость → главный риск.

<details>
<summary>Ответ</summary>

Пример: «Контекст → CAC/CPO по UTM → мгновенно → рост цены аукциона»; «SEO → органика/лиды → 6–12 мес → зависимость от алгоритмов»; «Пуши своей базы → реактивация/дёшево → мгновенно → усталость и отписки».
</details>

## Шпаргалка

1. Каналы = платный перформанс (быстро, измеримо, дорожает), активы (SEO/бренд/рефералы — медленно, дёшево), нерезкое (ТВ — спецметоды).
2. Тип рекламы → показатель: поиск ловит спрос, медийка/ТВ формируют, блогеры конвертируют доверием.
3. Метрика подбирается под механику канала; единый CPO для всех — несправедливость к верху воронки.
4. Игла перформанса: LTV/CAC < 1–3, растущий CAC при ровном LTV → строить активы и поднимать LTV.
5. Портфель каналов оценивают целиком (гео/эксперименты), каналы взаимодействуют.
