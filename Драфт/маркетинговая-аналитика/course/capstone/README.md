# Капстоун: мини-исследование рынка (урок 7.3)

Синтетический датасет «ЕдаДома» для итогового проекта. Постановка, этапы и критерии — в [уроке 7.3](../modules/M7/lesson-7.3.md).

## Данные

| Файл | Строки | Что внутри |
|---|---|---|
| `data/registrations.csv` | ~38,9 тыс. | регистрации 26 недель: `user_id, week, channel, city, b2b` |
| `data/orders.csv` | ~78,8 тыс. | заказы: `user_id, order_week, channel, city, b2b, revenue, margin` + флаги гео-пилота `promo_city, after, big_basket` |
| `data/open_ends.csv` | 300 | открытые ответы «что мешает заказывать чаще»: `respondent, answer, true_category` (истина — для валидации разметки) |
| `data/grid.csv` | 240 | мини-решётка (12 респондентов × 5 элементов × 4 конструкта): `respondent, element, construct, rating` (1 = первый полюс) |

Сюжет: направление **офисных заказов (b2b)**; в `msk`/`spb` с недели 14 действует промо-механика «−15% на корзины от 2000 ₽» (эффект вплавлен в заказы). Регенерация: `python3 course/capstone/generate_capstone.py` (seed фиксирован — данные воспроизводимы).

## Как выполнять

Работайте в pandas/jupyter поверх CSV. Последовательность — по уроку 7.3: постановка → когорты/LTV b2b vs b2c → гео-DiD пилота (+RDD-окно у порога 2000) → разметка open-ends с κ-валидацией → карта решётки → отчёт.

**Ревьюеру**: эталонные числа — `python3 course/capstone/solutions/check.py` (LTV12 сегментов, DiD пилота, распределение категорий, карта). Критерии оценки — таблица в уроке 7.3.
