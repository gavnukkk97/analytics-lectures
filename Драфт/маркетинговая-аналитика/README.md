# Маркетинговая аналитика — драфт курса

Полный курс «Маркетинговая аналитика: от метрик до ИИ-фабрики исследований» в разработке. Порядок работы: здесь лежит **черновик** (план + уроки + практики по мере написания); когда занятие прочитано студентам и презентация собрана — финальные материалы отправляются в основную папку репозитория («Лекция NN …») и появляются в карте занятий корневого README.

**Статус: план готов целиком, уроки пишутся по порядку.**

## Формат уроков

Цель → Зачем аналитику → Теория → Разбор на данных (числа совпадают с выводом практики) → Подводные камни → Практика → ДЗ с ответами → Шпаргалка → Источники. Сквозной кейс — «ЕдаДома» (доставка еды). Практики — самодостаточный Python (`numpy pandas matplotlib`), синтетика с seed:

```sh
python3 "Драфт/маркетинговая-аналитика/course/modules/M2/practice/practice_2_2.py"
```
