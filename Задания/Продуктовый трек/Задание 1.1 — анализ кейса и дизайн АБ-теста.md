# Задание 1.1 (продуктовый трек). Анализ кейса и дизайн А/Б-теста

**Формат:** презентация.

## Формальная постановка

1. Выберите **один кейс** из списка (возможно до двух команд на случай,
   если тема популярная).
2. Проведите **анализ текущего состояния продукта**:
   - конкурентное окружение;
   - текущие продуктовые метрики и негативные сигналы.
3. Найдите и сформулируйте **1–3 ключевых проблемы/ограничения** продукта.
4. Предложите **конкретное решение/инициативу**, которая способна повысить
   указанные метрики.
5. Спроектируйте **дизайн А/Б-теста** (или другой способ проверки качества
   решения) по вашему решению:
   - гипотеза;
   - метрики для оценки успеха (primary, secondary).
6. Подготовьте **презентацию**, структурированную по этим блокам.

## Кейсы

1. **E-grocery** (сервис быстрой доставки продуктов) — рост частоты заказов.
2. **Финтех-приложение** (кэшбэк / накопительный счёт) — активация новых
   пользователей.
3. **Стриминг-сервис** (музыка или видео) — отток подписчиков.
4. **Edtech-платформа** — конверсия из триала в платную подписку.
5. **Такси-агрегатор** — удержание после первой поездки.
6. **Маркетплейс** — конверсия в карточке товара и средний чек.
