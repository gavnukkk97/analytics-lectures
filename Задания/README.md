# Задания

В блоке лекций два трека — **маркетинговая аналитика** и **продуктовая
аналитика**. В каждом треке по два задания: основное (стратегия / кейс
с А/Б-тестом) и дашборд.

| Трек | Задание | Формат |

| Маркетинговый | [М2. Дашборд / макет дашборда для отдела маркетинга](Маркетинговый%20трек/Задание%202%20—%20дашборд%20для%20отдела%20маркетинга.md) | дашборд или макет |
| Продуктовый | [П1. Анализ кейса и дизайн А/Б-теста](Продуктовый%20трек/Задание%201.1%20—%20анализ%20кейса%20и%20дизайн%20АБ-теста.md) | презентация |
| Продуктовый | [П2. Дашборд для продукта / решения](Продуктовый%20трек/Задание%201.2%20—%20дашборд%20для%20продукта.md) | дашборд или макет |

## Общие правила

- **Кейс выбирается один на команду и не повторяется** между командами.
  Если кейс очень популярный — по согласованию отдадим максимум двум командам.
- Формат внутри заданий — максимально свободный: работающий дашборд,
  макет в Figma, отрисовка «в пэинте» — всё ок, главное логика и структура.
- Дашбордные задания (М2 и П2) можно делать как в рамках своего кейса
  из первого задания, так и отдельно от него.
